# Plugins

This directory contains Agora plugin integrations.

Each v0.1 plugin root has generated native metadata for Claude Code and ChatGPT/Codex:

```text
plugins/<id>/
├── .claude-plugin/plugin.json
└── .codex-plugin/plugin.json
```

These files are generated by `scripts/generate_marketplaces.py` from the canonical registry. Do not hand-edit generated metadata; change the registry or generator and regenerate instead.

A plugin may additionally define one or more MCP servers, scholarly skills/instructions, launch or adaptation logic, and supporting resources as later implementation phases add real functionality. Third-party upstream implementations should normally be referenced rather than vendored.

The Phase 2 manifests are intentionally metadata-only until the corresponding MCP/runtime integration exists.
