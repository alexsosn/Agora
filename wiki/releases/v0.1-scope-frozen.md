# Agora v0.1 — First Implementation Scope

This document fixes the resource scope of Agora's first implementation.

The first implementation consists of **four plugin families**:

1. **Context-Fabric** — one provider plugin exposing the complete current Context-Fabric corpus catalog, plus TLHdig-TF.
2. **Perseus** — integration of `tonyjurg/Perseus-mcp`.
3. **Sefaria** — independent Sefaria MCP integration.
4. **SEDRA** — independent Beth Mardutho / SEDRA integration.

The resource list below is the implementation target, not a set of optional future candidates.

## Context-Fabric corpus baseline

The Context-Fabric documentation page says it catalogs "40+" known corpora, but the current `CorporaTable.tsx` source contains **35 concrete corpus entries**. For v0.1, Agora uses those concrete entries as the authoritative baseline rather than the prose count.

## Greek Text-Fabric collection exception

Several PTHU Greek repositories in the baseline are **collections of many independent Text-Fabric corpora**, commonly one work/text per TF corpus. Direct repository inspection shows this applies to at least:

- `pthu/bible`;
- `pthu/patristics`;
- `pthu/greek_literature`.

Agora must distinguish:

- **marketplace/resource granularity:** each repository remains one registered Context-Fabric collection resource;
- **runtime granularity:** individual works remain separately discoverable and loadable TF corpora.

The collections must not become thousands of top-level marketplace plugins. Instead, Agora discovers current members lazily from upstream Git tree metadata, derives stable internal IDs from dataset paths, and acquires/caches/loads selected members where practical.

This means v0.1 support for these collection resources is not satisfied merely by adding registry rows. Agora must support member discovery and member-level loading through the Context-Fabric integration.

The detailed design is in [`ref-context-fabric-collections.md`](../architecture/ref-context-fabric-collections.md).

## Additional Context-Fabric corpus

### `TLHdig-TF`

- Upstream: `alexsosn/TLHdig-TF`
- Language: Hittite
- Provider: Context-Fabric MCP
- TF path/version: `tf/0.1.0`, selected explicitly while the repository follows its default branch
- Agora resource integration status: **Community**

TLHdig-TF is intentionally part of the first implementation. Agora records and resolves its source configuration but does not maintain suitability or data-quality claims about the corpus. Users should consult the upstream documentation matching the resolved source revision.

This gives the Context-Fabric plugin an initial baseline of **36 resources**: 35 from the current Context-Fabric catalog plus TLHdig-TF. Collection members inside resources such as `bible`, `patristics`, and `greek_literature` are not counted as additional marketplace resources.

## Independent MCP integrations

### Perseus

- Upstream: `tonyjurg/Perseus-mcp`
- Main resources: Perseus Digital Library / Scaife
- Mode: local MCP using remote Perseus/Scaife services
- Plugin ID: `perseus`

### Sefaria

- Provider: Sefaria
- Mode: hosted official Texts MCP endpoint, with transport adaptation only where a client requires it
- Plugin ID: `sefaria`

### SEDRA

- Provider: Beth Mardutho / SEDRA IV
- Mode: independent MCP integration
- Plugin ID: `sedra`

## Verification policy for v0.1

The implementation target and integration-verification state are separate dimensions.

- All resources in this document must be represented in the v0.1 registry and reachable through the appropriate plugin architecture.
- The **plugin runtime/integration** may be Verified while individual resource acquisition/loading paths carry their own `verified`, `community`, or `experimental` integration status.
- Collection resources may additionally carry per-member integration status; a broken Agora loading path for one member must not automatically invalidate the whole collection.
- Agora does not assess or restate upstream corpus suitability or data quality. Users must consult the original repository or corpus publisher's documentation.

## Scope rule

The first implementation is complete only when:

- the Context-Fabric plugin represents all 35 current Context-Fabric catalog entries;
- TLHdig-TF is available through the Context-Fabric plugin;
- Perseus-MCP, Sefaria, and SEDRA are independently installable integrations;
- every included resource has provenance, software/data licensing metadata where determinable, and a resource-level integration-verification status;
- large collection repositories remain collection resources rather than exploding into one marketplace plugin per text;
- collection members can be discovered, resolved to stable internal IDs, acquired/cached where needed, and loaded as individual Context-Fabric corpora.

Resources outside this document belong to post-v0.1 expansion unless explicitly added to the scope later.
